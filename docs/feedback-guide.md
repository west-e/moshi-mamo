# 試作品を見てもらうときの手引き

目的: 「固定電話を使う高齢者」と「離れて暮らす家族」という想定が合っているか、画面と音が通話中に伝わるかを、実際の人に確かめる。
聞けたことだけを記録する。聞けなかった感想を補ったり、言い換えて都合よくまとめたりしない。

## 事前に伝えること（同意）
- 見てもらうのは**架空の会話**で動く試作品で、本物の電話にはまだつながっていないこと。
- 感想を、名前を出さずにハッカソンの提出物（公開される資料・動画）で使ってよいか。だめなら記録しない。
- 本人の実際の通話や、ご自身の被害の詳細は聞かない（話してくれた場合も、本人の了承がなければ記録しない）。
- 途中でやめてよいこと。

## 見せる順番（10分程度）
1. **利用者画面だけを見せる**（`#/user` を別タブで開き、開発画面は隠す）
   - 架空の「普通の家族の電話」（T1）を流す → 青い画面のまま
   - 架空の「警察を名乗る電話」（T3）を流す → 黄色 → 赤に変わる
   - 音を有効にしておく
2. 何も説明せずに、下の質問1〜3を聞く（初見で伝わるかを確かめるため）
3. 仕組みを簡単に説明してから、質問4〜8を聞く

## 質問
初見で
1. いま画面に何と出ていますか。これを見たら、あなたは何をしますか。
2. 文字の大きさ・色・音は、電話をしながらでも気づけそうですか。
3. 分かりにくい言葉や、怖すぎる・きつすぎると感じた表現はありますか。

説明のあとで
4. 普段、知らない番号からの電話にはどう対応していますか。（高齢の方に）／ご家族の電話について、どんなことが心配ですか。（家族の方に）
5. 普通の電話で、たまに「ちょっと待って」と出てしまうことがあったら、どう感じますか。
6. 警告が出るまで数秒かかります。どのくらいまでなら待てますか。
7. 電話の内容を AI（Claude）に送って判断する仕組みについて、気になることはありますか。
8. 自宅の電話（またはご家族の電話）に付けたいと思いますか。付けるなら、何があれば安心ですか。

## 記録の書き方（`docs/feedback/` に1人1ファイル）
名前・住所・電話番号など、個人を特定できることは書かない。

```markdown
# フィードバック A
- 日付: 2026-11-0X
- 立場: 高齢の利用者 / 離れて暮らす家族 / その他
- 年代: 70代 など（任意）
- 公開資料での利用: 可 / 不可
- 見せたもの: T1, T3（利用者画面のみ → 開発画面）

## 初見での反応（質問1〜3）
- 発言はできるだけそのまま書く。「」で囲む。

## 説明後（質問4〜8）
-

## 記録者の観察
- 迷った箇所、表情、聞き返した言葉など

## 試作品で直したいこと
-
```

## まとめ方
- 全員分を記録してから、良かった点・困った点・意見が分かれた点を分けて整理する。
- 否定的な意見も削らない。
- 人数が少ないので「◯割が使いたい」のような割合の主張はしない。「◯人中◯人がこう言った」と書く。
