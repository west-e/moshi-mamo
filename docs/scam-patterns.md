# 特殊詐欺の手口と、台本づくりの材料

> 2026-11-03 時点で、警察・自治体・報道の公開情報から整理した。言い回しは要約・言い換えで、実際の通話や公開音声の書き起こしではない。
> 目的: もしまもの検証用・デモ用の**架空の台本**を書くための材料。実在の人名・番号・機関の正式名は台本に入れない（「〇〇」で伏せる）。

## 手口ごとの流れ

### 1. オレオレ詐欺（息子・孫などを名乗る）
| 段階 | よくある内容 |
|---|---|
| 名乗り | 「おれだよ」と名前を言わない。声が違うのは「風邪」「のどを痛めた」「事故で」と言い訳する。「携帯をなくして番号が変わった」 |
| 不安・口実 | 交通事故の示談金、会社のお金が入ったかばんの紛失・使い込み、会社のトラブル、借金の保証人、痴漢などのトラブル、妊娠させた など |
| 急がせる | 「今日中に」「このままだとクビ／警察沙汰」 |
| 劇場型 | 上司・同僚・弁護士・警察官を名乗る別の人が次々に電話に出る |
| 口止め | 「父さんには言わないで」「会社に知られたら困る」「電話を切らないで」 |
| 受け取り | 本人は行けないので「後輩」「同僚」「弁護士の事務員」が家に取りに来る（手渡し） |

見分け方: 元の番号に自分からかけ直す。家族しか知らないことを聞く。お金の話が出たら、その場で決めず電話を切って家族に確かめる。

### 2. ニセ警察詐欺（警察官を名乗る） — 令和7年の特殊詐欺の約4割
| 段階 | よくある内容 |
|---|---|
| 名乗り | 警察署・警視庁の捜査員を名乗る。国際電話番号（+ から始まる）からかかってくることがある |
| 不安・口実 | 「あなたの口座が犯罪（マネーロンダリング・詐欺）に使われた」「逮捕状が出ている」「容疑がかかっている」 |
| 別の手段へ誘導 | LINE などの SNS に移させ、ビデオ通話で偽の警察手帳や逮捕状を見せる。最近は警察を装う偽サイトでビデオ通話をさせる例も |
| 口止め | 「秘密の捜査なので家族にも銀行にも話すな」 |
| 要求 | 「資金調査」「無実の証明」「紙幣番号の確認」などの名目で、振込・現金の提出・暗号資産をさせる |

見分け方: 警察が SNS に誘導する、ビデオ通話で取り調べる、警察手帳や逮捕状の画像を送る、お金を振り込ませることはない。電話を切り、自分で最寄りの警察署か #9110 にかけて確かめる。

### 3. 預貯金詐欺・キャッシュカード詐欺盗（カードをだまし取る・すり替える）
| 段階 | よくある内容 |
|---|---|
| 名乗り | 警察官、銀行協会・金融機関の職員、百貨店の職員などを名乗る |
| 不安・口実 | 「あなたのカードが不正に使われている」「カードを新しくする必要がある」 |
| 聞き出し | 銀行名、カードの枚数、暗証番号 |
| 受け取り | 「これから職員が行く」。封筒にカードと暗証番号を書いた紙を入れさせる。すり替え型では「封印するので印鑑を」と席を外させ、偽の封筒とすり替える |

見分け方: 警察や銀行が暗証番号を聞いたり、カードを預かりに来たりすることはない。

### 4. 還付金詐欺（お金が戻ると言って ATM へ行かせる）
| 段階 | よくある内容 |
|---|---|
| 名乗り | 市役所・区役所、年金事務所、保険の担当を名乗る |
| 口実 | 「医療費・保険料の払い戻しがある」 |
| 急がせる | 「手続きの期限が過ぎている」「今日までなら ATM でできる」 |
| 誘導 | 近く（無人やスーパーの中）の ATM へ行かせ、携帯電話で操作を指示する |
| 実際 | 払い戻しの手続きのふりで、自分の口座から振り込ませる |

見分け方: 役所や年金事務所が ATM での手続きを求めることはない。ATM でお金は戻らない。

### 5. 自動音声ガイダンスから始まる詐欺
| 段階 | よくある内容 |
|---|---|
| 自動音声 | 総務省・通信会社・料金の回収会社を名乗る録音音声。「2時間後に電話が使えなくなる」「未払いの料金がある」 |
| 操作させる | 「詳しくは1番を押してください」 |
| 人に切り替わる | 職員を名乗る人が出て、「あなたの番号が犯罪に使われた」などと言い、警察を名乗る人に回す（ニセ警察詐欺につながる） |

見分け方: 自動音声で電話の停止や未払いを告げられても、番号を押さずに切る。名乗った機関に、自分で調べた番号でかけ直す。

### 6. 架空料金請求詐欺
最初の接触はメール・SMS（約半分）やポップアップが多く、電話は約2割。未払いの料金や「サポート」の名目で、電子マネーを買わせて番号を伝えさせる。

### 7. 予兆電話（アポ電）
住所・家族構成・在宅の時間・資産・取引している金融機関などを探る電話。令和7年は 331,653件。詐欺や強盗の下調べのおそれがある。もしまもでは「曖昧な電話」として扱い、強い注意は出さない設計。

## もしまもで試しておくべきこと
練習用の台本（`eval/scenarios/practice/`、Claude が書いた架空の11本）で試した結果を併記する。詳しくは `docs/DEVLOG.md`「手口の調査と練習用の台本」。

- **自動音声の電話**: 録音音声の言い回し（「1番を押して」「電話が使えなくなる」）が文字になったとき、判定できるか。
  → 詐欺（P5）は発話1から注意。本物の病院の予約確認（P10）は反応なし。
- **SNS・ビデオ通話への誘導**: 「LINE で」「ビデオ通話で警察手帳を見せる」は強い兆候だが、今の判定指示の兆候一覧には書いていない。追加するなら判定指示の変更になるので、調整用で測ってから決める。
  → ニセ警察（P2）は、誘導の前（発話3〜4）に強い注意になった。いまは追加しない。
- **劇場型**: 途中で別の人（上司・弁護士・警察）に代わる。話者が「不明」の音声入力で流れを追えるか。
  → 文字の入力（P1）では検知できた。音声入力では未確認（マイクの練習で確かめる）。
- **見分けにくい正常な電話**: 本物の警察からの落とし物の連絡、本物の家族の事故の連絡、本物の役所からの書類の案内など。単語や名乗りだけで警告しないかを確かめるため、詐欺の台本と同じくらい必要。
  → **弱点が見つかった。** 本物のカード会社の確認（P8）で、本人が「暗証番号は言わなくていい？」と聞いた時点で強い注意が出た（Haiku、3回とも）。判定の指示に「兆候は相手の言動から判断する」を加えて、強い注意は出なくなった。注意（黄）は最後まで残る。

## 台本の書き方（人が書く場合）
- 1本 8〜15発話。話者は「相手」「本人」。1文は短く、話し言葉で。
- 固有名は「〇〇」で伏せる（〇〇警察署、〇〇銀行、たけし などの下の名前は可）。実在の番号は書かない。
- 詐欺の台本は、**最初は普通の会話から始め、少しずつ要求に近づける**（いきなり「お金を払え」にしない）。
- 正常な電話の台本も書く。特に「詐欺に似ているが本物」の電話。
- 期待する結果（どの発話までに注意・強い注意が出るべきか、または出てはいけないか）を、台本と別に書いておく。
- 判定する側（Claude）と書く側が同じだと偏るので、**評価に使う台本は人が書く**。Claude が書いた台本は、マイクの練習・デモ・調整用に使う。
